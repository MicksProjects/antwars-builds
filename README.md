# Ant Wars – game builds

Release downloads for **Ant Wars**, a garden-scale real-time strategy game about rival ant colonies.

This repository only hosts the finished game builds that the game's built-in updater downloads. It contains no source code.

- Play / download: https://antwars.itch.io/ant-wars (Windows and macOS)
- Community: https://discord.gg/NgNGnC9URJ
